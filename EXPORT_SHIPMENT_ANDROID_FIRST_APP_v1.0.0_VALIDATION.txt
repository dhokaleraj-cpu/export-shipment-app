Export Shipment Android First-App v1.0.0
========================================
Architecture
- One hardened Android WebView only.
- Export Shipment / Streamlit owns all menus, navigation, permissions and login flow.
- No native route map, no query-route injection and no Android-side page switching.
- Cookies, DOM storage and third-party cookies are enabled to preserve the web login/session.
- File upload chooser and authenticated DownloadManager downloads are supported.
- HTTPS only; cleartext traffic disabled.

First launch
- Enter the existing Export Shipment HTTPS app URL once.
- The URL is stored locally in Android SharedPreferences.
- It can be changed later from the top-right menu.
