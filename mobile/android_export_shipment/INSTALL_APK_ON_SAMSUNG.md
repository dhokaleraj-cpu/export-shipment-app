# Install Export Shipment Mobile on Samsung / Android

1. In GitHub open **Actions → Export Shipment Android First-App APK**.
2. Open the successful workflow run.
3. Download artifact **Export-Shipment-Mobile-FIRST-APP-APK**.
4. Extract it and install `Export_Shipment_Mobile_FIRST_APP_v1.0.0_TEST.apk`.
5. If Android asks, allow installation from the browser/file-manager you used.
6. Open **Export Shipment Mobile**.
7. On first launch, enter the HTTPS URL of the existing Export Shipment web app and tap **SAVE & OPEN EXPORT SHIPMENT**.

The app uses the same login, permissions and database as the web application.
